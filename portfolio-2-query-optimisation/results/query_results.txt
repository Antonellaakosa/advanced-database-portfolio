Management report over all 1,000,000 loans

SQL (original form):
SELECT b.city, date_trunc('year', l.loaned_at) AS year, count(*) AS loans
       FROM loan l JOIN branch b ON b.branch_id = l.checkout_branch_id
       GROUP BY b.city, date_trunc('year', l.loaned_at) ORDER BY b.city, year

Q9. Outstanding fines for a member
What member 1500 still owes (joins loan, fine, payment)

SQL (original form):
SELECT f.fine_id, f.amount, COALESCE(SUM(p.amount), 0) AS paid,
              f.amount - COALESCE(SUM(p.amount), 0) AS outstanding
       FROM loan l JOIN fine f ON f.loan_id = l.loan_id
                   LEFT JOIN payment p ON p.fine_id = f.fine_id
       WHERE l.member_id = 1500 AND NOT f.waived
       GROUP BY f.fine_id, f.amount
       HAVING f.amount - COALESCE(SUM(p.amount), 0) > 0

First 5 rows returned:
 fine_id | amount | paid | outstanding 
---------+--------+------+-------------
  114476 |  75.00 |    0 |       75.00
  124775 |  25.00 |    0 |       25.00
(2 rows)

 total rows returned
